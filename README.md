# snap-and-listen-reader
A low-cost prototype that helps visually impaired users read a printed page: camera → OCR → AI correction → TTS, with audio/haptic guidance.


# snap-and-listen-reader

## 项目简介

`snap-and-listen-reader` 是一个帮助视力障碍用户阅读纸质页面的低成本开源原型。用户用手机拍一页纸，应用通过 **相机 → OCR → AI 纠错与分段 → TTS 语音朗读** 的流程把内容读出来，并用音频和触觉提示引导用户对准页面、改善光线和处理识别失败。当前处于需求验证和原型规划阶段，欢迎视障用户、开发者和无障碍研究者参与共创。

当前状态：**需求验证 / 原型规划阶段**。项目尚未完成，欢迎视障用户、无障碍研究者、开发者和学生参与共创。

## 项目目标

让用户用手机拍一页纸，就能听到这一页的内容：

**拍照 → OCR 识别 → AI 纠错与分段 → TTS 语音朗读 → 语音控制**

## 目标用户

- 视力障碍者，尤其是需要阅读纸质书、文件、说明书的人群
- 低视力用户（视觉辅助仅作为可选功能）
- 陪护者、无障碍志愿者和测试协作者

## 首个原型功能（MVP）

1. 打开 App，听到“请将摄像头对准一页纸”
2. 拍照或自动检测页面
3. 设备端 OCR 识别文字
4. AI 可选：纠错、分段、简化长句
5. TTS 从第一小段开始朗读，不等待整页处理完成
6. 支持简单语音命令：`下一段`、`重复`、`暂停`、`继续`
7. 异常反馈：
   - 页面偏左/偏右：短触觉脉冲 + 左右声道的提示音 + 语音提示
   - 光线不足：低音提示 + “请增加光线”
   - OCR 置信度低：停止朗读，三次短振动 + “请保持稳定并重新对准”

## 非目标（第一版不做）

- 不训练自研大模型
- 不做硬件
- 不承诺替代专业屏幕阅读器
- 不先做复杂社交、账号、云同步功能
- 不把视觉反馈作为核心交互；视觉仅服务低视力用户或调试

## 建议技术栈

| 模块 | 低成本方案 |
|---|---|
| 相机 | Android CameraX，`STRATEGY_KEEP_ONLY_LATEST` |
| OCR | Google ML Kit Text Recognition v2；中文可评估 PaddleOCR |
| AI 纠错/分段 | 可选 LLM API：OpenAI / DeepSeek / Qwen / 智谱等 |
| TTS | Android 系统 TTS 起步；后续再评估 Azure / Google / 讯飞 |
| 语音命令 | Android `SpeechRecognizer` 起步 |
| 触觉反馈 | Android `Vibrator` / `HapticFeedback` |
| 视觉辅助 | 高对比度放大、拍摄框提示，仅作可选 |

原则：优先使用系统能力、免费额度和开源组件，避免一开始自研模型或做硬件。

## 延迟策略

- OCR 在设备端完成，减少服务器往返
- 文本切分为小段，第一段识别后立即 TTS 朗读
- 后续段落并行 OCR / 纠错 / 合成
- 不等待完整音频文件生成
- 记录各阶段延迟：拍照、OCR、AI、TTS 首段出声

## 隐私与安全

- 优先本地处理图片和 OCR 结果
- 如需上传到 AI API，必须明确告知用户并取得同意
- 不默认保存用户拍摄的文档图片
- 项目不提供医疗或法律建议

## 路线图

- [ ] 访谈 5–10 位视障用户，记录现有阅读方式和痛点
- [ ] 完成单页拍照 → OCR → TTS 的最小 Android 原型
- [ ] 加入首段快速朗读和延迟测量
- [ ] 加入页面未对准、光线不足、低置信度的音频/触觉反馈
- [ ] 邀请种子用户测试“拍一页、听一页”的完成率
- [ ] 根据反馈决定是否加入 AI 纠错、中文优化和低视力视觉辅助
